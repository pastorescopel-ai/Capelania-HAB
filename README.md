
# 🏥 Gestão de Capelania HAB

Sistema de gestão hospitalar para capelães, focado no registro de atividades de capelania.

## 🚀 Como Executar o Projeto

1.  **Clone o repositório** ou baixe os arquivos.
2.  **Instale as dependências** (caso esteja usando npm/yarn).
3.  **Abra o `index.html`** no seu navegador ou use um servidor local (Live Server).

## 🛠️ Configuração do Banco de Dados

Para sincronizar dados entre dispositivos, você pode configurar:

*   **Firebase**: Vá em Administração e cole seu `firebaseConfig`.
*   **Google Sheets**: Vá em Administração e cole a URL do seu `App Script` implantado como web app.
